# Internationalization Review Notes

## Translation integrity

When reviewing locale changes:

- compare locale key sets
- check namespace consistency
- identify fallback languages or key fallbacks that hide missing translations
- check missing interpolation values
- check plural and variable forms when relevant

Fallback behavior can keep the UI functional while shipping untranslated text. Report it when the
product is expected to provide the locale being reviewed.

## Routing and SEO

For localized public pages, check:

- unsupported locale routes do not silently render fallback content
- canonical URLs point to the current locale equivalent
- `alternates.languages` maps equivalent localized pages
- `x-default` matches the project's default-locale strategy
- locale redirects do not loop
