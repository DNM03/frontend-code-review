# Case Template

Create one directory per evaluation case:

```txt
cases/
└── 01-mutation-form/
    ├── README.md
    └── CreateJobForm.tsx
```

Document:

```md
# Case Name

## Category

Data fetching and mutations

## Review scope

Review the files in this directory.
```

Recommended cases:

- mutation pending and error states
- query-key completeness
- Server and Client Component boundaries
- derived state in Effects
- icon-only accessibility
- clean baseline with no seeded issues
- layout canonical URLs
- responsive Tailwind grids
- localization key mismatch hidden by fallback behavior
